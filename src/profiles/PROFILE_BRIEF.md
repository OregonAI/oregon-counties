# Writing a county profile

Read this, then `src/ingest_counties.py` (the discovery modes and the ingest loop), then
`src/fetch.py`. Everything below assumes you have.

You write **exactly two files** and touch nothing else:

    src/profiles/<county>.py      the profile (you author it)
    _meta/sources/<county>.yml    the manifest (GENERATED by --discover, you review it)

Never edit a shared file. Never edit another county's files. If you believe a shared module
needs a change, say so in your reply instead of making it — seven workers are running
concurrently and a shared edit is a merge conflict at best.

## The profile

```python
"""<County> County — one paragraph on how this county actually publishes, and what is
strange about it. Write what you VERIFIED, not what you assume."""

PROFILE = {
    "slug": "lane",                    # filename stem; registry slug minus -county
    "name": "Lane",
    "discovery": "link-list",          # default mode for this county
    "site": "https://lanecountyor.gov",
    "crawl": {
        "decision": "proceed",         # proceed | excluded | unavailable
        "checked": "2026-07-31",
        "basis": "why — one or two sentences",
        "hosts": [
            {"host": "lanecountyor.gov",
             "robots_url": "https://lanecountyor.gov/robots.txt",
             "ai_block": False,
             "content_signal": None,
             "notes": "disallows /Search/ /WebApi/ /WebServices/; the PDF tree is open"},
        ],
    },
    "upstream_signal": "what announces a change here, and how often it really moves",
    "families": {
        "code": {
            "listing_url": "https://...",
            "link_re": r'href="([^"]+LC\d+\.pdf)"',   # ONE group: the href
            "format": "pdf",
        },
        # ... orders, policies, land-use
    },
}
```

Available `discovery` values are the keys of `DISCOVERY` in `ingest_counties.py`:
`link-list`, `mco-s3`, `municode-api`. A family may override with its own `"discovery"` key.

**If none of them fits**, define a module-level `discover(profile, family, cfg)` returning
`[{"url": ..., "name": ..., "title": ...(optional)}, ...]`. It overrides the mode entirely for
every family in your county. Prefer this over bending a generic mode into a shape it does not
have — a mode that half-works for you will silently half-break for the next county that uses it.

To skip a family, give it `{"skip": "one sentence saying why"}`. A family the county does not
publish is a real finding and must be recorded as a skip with its reason, not omitted.

## Rules

1. **Verify before you write.** Every URL in your profile must have been fetched by you in
   this session. The 36-county survey attached to your task is a starting point and was
   accurate on 2026-07-31 — it is not a substitute for checking. If a URL in it has moved,
   that is a finding: say so in your reply.

2. **Draft text is the worst possible output.** Redline and proposed documents sit in the
   same directories as adopted law in at least five counties. `fetch.looks_like_draft()`
   filters the known patterns, but it is a filename heuristic and it will not save you from a
   county that names drafts differently. Look at the actual listing. If you see adopted and
   draft versions distinguished some other way, encode it in `exclude_re` and say so.

3. **`skip` and "not found" are different from "blocked".** If a host refuses an
   honestly-identified fetch, set `crawl.decision` accordingly and record the host. Do not
   retry with a browser User-Agent — `src/fetch.py` deliberately does not do this and neither
   should you. Being refused is a fact worth recording; disguising ourselves is not a
   workaround we are taking.

4. **Do not estimate counts.** Run `--discover` and report what it actually found.

5. Aim for the **county code and land use first** — they are the families with real authority
   edges to ORS/OAR. Administrative policy is valuable but is the least uniform.

## When you are done

Run, and paste the real output in your reply:

    python3 src/ingest_counties.py --discover <county>

not a navigation page:

    python3 src/ingest_counties.py --only <county> --limit 3

Reply with: the counts per family, the discovery mode(s) you used, anything in the survey
that turned out to be wrong, and the single thing most likely to break this county later.
Do not paste the profile or the manifest back.
