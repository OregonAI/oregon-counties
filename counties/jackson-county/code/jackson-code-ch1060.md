Public Transportation

EDITOR
'S NOTE:  Board Order 66-75, passed May 9, 1975, established the Rogue
Valley Transportation District and set boundaries therefor. Board Order 238-80, passed
June 11, 1980, established requirements for disbursement of funds in connection with the
District.

There are no sections in Chapter 1060. This chapter has been established to provide a
place for cross references and any future legislation.
