 The following is a chronological listing of legislation of Clatsop County, Oregon. Each entry in this table contains a reference intended to give the user of the code the current disposition (location) of the content of each particular ordinance and indicating its inclusion or exclusion in the Code. [Enabling legislation which is not general and permanent in nature is considered to be non-Code material (Special).] A complete listing, including disposition, of all legislation reviewed in conjunction with the original publication of the Code is on file in the office of the Clerk. 1.  "Special" ordinances, such as specific agreements and contracts, rezones of land, or other enactments not of a permanent or long-term nature, are usually not codified. They may, however, still be in effect. A user of the Code wishing to review such an ordinance should consult with the office of the Clerk for additional information. 2.  A disposition such as 2.08 refers to a chapter of this Code, and indicates that some or all of the content of a particular ordinance is still in effect, and may be found in the section(s) of that chapter. 3.  A disposition such as 2.08.010 [2.08.030] indicates that the ordinance mislabeled the amending chapter/section and the number in brackets is the correct one.
